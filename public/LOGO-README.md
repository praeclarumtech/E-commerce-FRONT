# Logo & Favicon

- **`logo.svg`** – Used in the app sidebar and header. Replace this file to change the logo site-wide (keep same filename for no code changes).
- **`favicon.svg`** – Browser tab icon. Replace this file to change the favicon.

To use different paths or filenames, update `src/shared/constant/branding.ts` (`LOGO_URL` and `FAVICON_URL`). For favicon, also update the `<link rel="icon">` in `index.html`.
